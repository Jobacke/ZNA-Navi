Einstellungen

Serverliste

Die Ziele kommen aus der Datei zna.json in deinem GitHub-Repo. Neue Handys laden sie beim ersten Start automatisch. Änderst du die Datei, bietet jedes Handy beim nächsten Öffnen das Update an.

Hochladen zum Server

Damit neue oder geänderte Ziele dauerhaft in zna.json landen und auf allen Handys ankommen, braucht die App einen GitHub-Schlüssel – nur für dieses eine Repo:
  1. github.com → Profilbild → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Name „ZNA-Navi“, Ablauf z. B. 1 Jahr, Repository access → Only select repositories → ZNA-Navi
  3. Repository permissions → Contents → Read and write → Generate token → kopieren
  4. Unten einfügen → Verbindung testen
Der Schlüssel bleibt nur auf diesem Handy. Geht das Handy verloren: Schlüssel auf GitHub löschen.

App-Start

Öffnet sich statt der Navi-App eine Webseite, die andere Variante wählen.

Sortierung

Adresse per Siri

Kurzbefehle-App → neuer Kurzbefehl, Name z. B. „Navi Adresse“:
  1. Aktion „Nach Eingabe fragen“ (Text, Frage: „Wohin?“)
  2. Aktion „URL codieren“ (Eingabe: „Angefragte Eingabe“)
  3. Aktion „URL öffnen“: https://zna.vjbackhaus.de/?q= + „Codierte URL“
„Hey Siri, Navi Adresse“ → Adresse sagen → Treffer antippen → Waze fährt los.

Einzelnes Ziel per Siri

Ziel bearbeiten → Waze-Link kopieren → in Kurzbefehle-App Aktion „URL öffnen“ mit diesem Link → Kurzbefehl benennen (z. B. „ZNA Harlaching“).
