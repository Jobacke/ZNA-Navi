Einstellungen

Serverliste

Die Ziele kommen aus der Datei zna.json in deinem GitHub-Repo. Neue Handys laden sie beim ersten Start automatisch. Änderst du die Datei, bietet jedes Handy beim nächsten Öffnen das Update an.

Waze-Start

Öffnet sich statt Waze eine Webseite, die andere Variante wählen.

Sortierung

Adresse per Siri

Kurzbefehle-App → neuer Kurzbefehl, Name z. B. „Navi Adresse“:
  1. Aktion „Nach Eingabe fragen“ (Text, Frage: „Wohin?“)
  2. Aktion „URL codieren“ (Eingabe: „Angefragte Eingabe“)
  3. Aktion „URL öffnen“: https://zna.vjbackhaus.de/?q= + „Codierte URL“
„Hey Siri, Navi Adresse“ → Adresse sagen → Treffer antippen → Waze fährt los.

Einzelnes Ziel per Siri

Ziel bearbeiten → Waze-Link kopieren → in Kurzbefehle-App Aktion „URL öffnen“ mit diesem Link → Kurzbefehl benennen (z. B. „ZNA Harlaching“).
