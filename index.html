Einstellungen

Serverliste

Die Ziele kommen aus der Datei zna.json in deinem GitHub-Repo. Neue Handys laden sie beim ersten Start automatisch. Änderst du die Datei, bietet jedes Handy beim nächsten Öffnen das Update an.

Blitzer.de PRO

Die Rückkehr aus Waze, Google Maps, Apple Karten oder Blitzer.de zählt nie als neues Öffnen.
Einmal einrichten (Blitzer.de hat keinen direkten Link, daher über einen Kurzbefehl):
  1. Kurzbefehle-App → + → Aktion suchen: Blitzer.de → „Warnmodus starten“ (nicht „App öffnen“)
  2. Kurzbefehl oben umbenennen in Blitzer starten → Fertig
  3. iPhone-Einstellungen → Apps → Blitzer.de PRO → Standort: Immer
  4. In Blitzer.de: Menü → Einstellungen → Experten-Optionen → Warnungen im Hintergrund an
Beim Start springt iOS kurz in die Kurzbefehle-App. Zurück zu ZNA-Navi: oben links auf ◀ ZNA-Navi tippen.
Unten links erscheint dann ein Knopf, der Blitzer.de in den Ruhemodus schickt (iOS kann Apps nicht schließen – der Ruhemodus ist das Gegenstück: keine Warnungen, kein Internet, kaum Akku). Dafür einen zweiten Kurzbefehl anlegen: Aktion Blitzer.de PRO → „Ruhemodus aktivieren“, Name Blitzer Ruhe.

Hochladen zum Server

Damit neue oder geänderte Ziele dauerhaft in zna.json landen und auf allen Handys ankommen, braucht die App einen GitHub-Schlüssel – nur für dieses eine Repo:
  1. github.com → Profilbild → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Name „ZNA-Navi“, Ablauf z. B. 1 Jahr, Repository access → Only select repositories → ZNA-Navi
  3. Repository permissions → Contents → Read and write → Generate token → kopieren
  4. Unten einfügen → Verbindung testen
Der Schlüssel bleibt nur auf diesem Handy. Geht das Handy verloren: Schlüssel auf GitHub löschen.

App-Start

Öffnet sich statt der Navi-App eine Webseite, die andere Variante wählen.

Darstellung

Apple sperrt die Spracherkennung in Home-Bildschirm-Apps. Am schnellsten ist daher der Siri-Kurzbefehl: Mikrofon antippen → sofort sprechen → los.
Kurzbefehl einmal anlegen (Kurzbefehle-App → +), Name: ZNA Sprache
  1. Aktion „Text diktieren“ (Suchwort „diktieren“) → Sprache Deutsch, „Diktat beenden“: Nach Pause
  2. Variante A – direkt losfahren: Aktion „Route anzeigen“ bzw. „Wegbeschreibung anzeigen“ (Suchwort „Route“) → Ziel: Diktierter Text → App: Waze (oder Google Maps/Karten)
  3. Variante B – erst Treffer prüfen: statt Schritt 2 Aktion „URL codieren“ und dann „URL öffnen“ mit https://zna.vjbackhaus.de/?q= + „Codierte URL“ – die Adresse steht dann im Suchfeld (öffnet in Safari).
Für das Tastatur-Diktat muss unter iPhone-Einstellungen → Allgemein → Tastatur die Diktierfunktion an sein.

Sortierung

Der Standort wird bei jedem Öffnen ermittelt – das nächste Ziel steht oben. Ein Tipp auf das Fadenkreuz schaltet vorübergehend auf die hier gewählte Sortierung um.

Siri: „Meine Route“

„Hey Siri, Meine Route“ (oder am Helm Siri-Taste halten → „Meine Route“) → Siri fragt „Welches Ziel?“ → Zielnamen sagen → Waze fährt los.
  1. Der Kurzbefehl heißt Meine Route und fragt mit „Welches Ziel?“.
  2. Er lädt die Zielliste direkt von zna.vjbackhaus.de/zna.json – neue Ziele aus der Serverliste kennt er sofort.
  3. Es zählt der Anfang des Namens („beginnt mit“). Kurze, eindeutige Namen funktionieren am besten.
Ein Ziel, das nur auf diesem Handy gespeichert ist, kennt Siri erst nach dem Hochladen zum Server.

Einzelnes Ziel per Siri

Ziel bearbeiten → Waze-Link kopieren → in Kurzbefehle-App Aktion „URL öffnen“ mit diesem Link → Kurzbefehl benennen (z. B. „Route Harlaching“).
